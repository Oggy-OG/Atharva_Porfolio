# Atharva_Porfolio

Personal portfolio of **Atharva Vasant Mahajan** — front-end & UI/UX designer, AI data annotator
(RLHF / LLM evaluation) and Computer Science undergraduate.

Single-file site — no build step, no dependencies.

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8090
# → http://127.0.0.1:8090
```

## What's inside

- **Hero** — animated headline, role rotator, live counters
- **About / Experience** — Mercor, Handshake AI, OneForma, Outlier, Data Foundry, Ethara AI, Yuga Yatra Pvt Ltd
- **Projects** — gamified Android app, RLHF evaluation, code annotation, multimodal annotation
- **Design kit** — Canva, Git, GitHub, Google Workspace, annotation tools
- **Vibe Coder** — Claude Code, Cursor, Lovable.dev, Google AI Studio, Antigravity
- **Education & Achievements**, contact

Figma-canvas inspired theme: paper background, hard-shadow cards, custom cursor, marquee,
scroll reveals, magnetic buttons. Respects `prefers-reduced-motion`.
